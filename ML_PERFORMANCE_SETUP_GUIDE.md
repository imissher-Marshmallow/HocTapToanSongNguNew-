# ML Performance Records - Setup & Integration Guide

## 📊 Overview

The `ml_performance_records` table stores detailed metrics from every quiz attempt. This data powers:
- **AI Feedback Generation** - Analyze weaknesses and strengths
- **Adaptive Quiz Selection** - Focus on weak topics & cognitive levels
- **Progress Tracking** - Monitor student improvement over time
- **Trend Analysis** - Predict future performance

## 📋 Table Structure

```sql
ml_performance_records {
  id                BIGINT PRIMARY KEY
  user_id           BIGINT (links to auth.users)
  quiz_id           VARCHAR - "contest1", "adaptive", etc.
  exam_id           INT - 1-3 (easy), 4-5 (hard)
  
  score             INT - raw score (points)
  percentage        DECIMAL - 0-100%
  max_score         INT - usually 20
  
  topic             VARCHAR - "Đa thức", "Phương trình"
  difficulty_level  INT - Bloom's level 1-4
  
  cognitive_breakdown JSONB
  {
    "level1": { "correct": 5, "total": 5, "points": 10 },
    "level2": { "correct": 4, "total": 6, "points": 6 },
    ...
  }
  
  topic_mastery    JSONB
  {
    "Đa thức": { "correct": 4, "total": 5, "score": 80 },
    "Phương trình": { "correct": 2, "total": 5, "score": 40 }
  }
  
  weak_topics       JSONB - topics with <60% accuracy
  strong_topics     JSONB - topics with ≥80% accuracy
  
  trend_metrics     JSONB - improvement, momentum, trend
  time_on_task      JSONB - seconds, per-question avg
  answers           JSONB - { "q1": 0, "q2": 1, ... }
  
  quiz_type         VARCHAR - "adaptive", "contest", "practice"
  created_at        TIMESTAMP - when quiz started
  completed_at      TIMESTAMP - when quiz submitted
}
```

### C. Use Weak Areas for Next Quiz

**File:** `stem-project/backend/routes/adaptive.js`

```javascript
const { getTopWeakAreas } = require('../services/mlPerformanceService');

router.get('/api/adaptive/quiz/personalized', async (req, res) => {
  try {
    const { userId } = req.query;

    // 🎯 Get user's weak areas from previous quizzes
    const weakAreas = await getTopWeakAreas(userId, 5);
    console.log('[Adaptive] Weak areas for user:', weakAreas);

    // Generate adaptive quiz focusing on weak topics
    const allQuestions = getAllQuestions();
    const adaptiveQuiz = selectQuestionsForWeakAreas(
      allQuestions,
      weakAreas,
      20  // 20 questions total
    );

    res.json({
      quiz: adaptiveQuiz,
      focusTopics: weakAreas.map(w => w.topic),
      message: `Quiz focused on: ${weakAreas.map(w => w.topic).join(', ')}`
    });
  } catch (err) {
    console.error('Error generating adaptive quiz:', err);
    res.status(500).json({ error: err.message });
  }
});

// Helper: Select questions focusing on weak areas
function selectQuestionsForWeakAreas(allQuestions, weakAreas, count = 20) {
  const weakTopics = new Set(weakAreas.map(w => w.topic));
  
  // 40% from weak topics, 60% from others
  const weakCount = Math.round(count * 0.4);
  const otherCount = count - weakCount;

  let selected = [];

  // Select from weak topics first
  const weakQuestions = allQuestions.filter(q => weakTopics.has(q.topic));
  selected.push(...weakQuestions.sort(() => Math.random() - 0.5).slice(0, weakCount));

  // Fill remaining with other topics
  const otherQuestions = allQuestions.filter(q => !weakTopics.has(q.topic));
  selected.push(...otherQuestions.sort(() => Math.random() - 0.5).slice(0, otherCount));

  return selected.sort(() => Math.random() - 0.5);
}
```

## 🔗 Data Flow Summary

```
1. USER SIGNS UP
   ↓
   initializeUserMLPerformance(userId)
   → Creates empty ml_performance_records entry
   
2. USER SELECTS TOPIC & DIFFICULTY
   ↓
   Frontend: onClick → /api/adaptive/quiz/personalized?topic=Đa thức&examId=4
   ↓
   Backend: Filter questions_updated.json by topic & exam_id
   → Return 20 selected questions
   
3. USER TAKES QUIZ
   ↓
   Frontend: Submits answers to POST /api/results
   
4. BACKEND PROCESSES RESULTS
   ↓
   saveQuizPerformance({userId, answers, questions, ...})
   ↓
   Calculates:
   - cognitive_breakdown (level1-4 performance)
   - topic_mastery (per-topic scores)
   - weak_topics (topics < 60%)
   - strong_topics (topics ≥ 80%)
   - trend_metrics (improvement over time)
   ↓
   INSERT into ml_performance_records
   
5. AI FEEDBACK GENERATION (Optional)
   ↓
   Fetch weak_topics from latest ml_performance_records
   ↓
   Call OpenAI with: "User is weak in {{weak_topics}}. Generate feedback..."
   
6. NEXT QUIZ RECOMMENDATION
   ↓
   GET /api/adaptive/weak-and-strong/:userId
   ↓
   Shows user's weakest topics (prioritize for next quiz)
```

## ⚠️ Important Notes

1. **exam_id mapping:**
   - 1, 2, 3 = Normal/Easy difficulty
   - 4, 5 = Hard difficulty

2. **cognitive_breakdown** always has levels 1-4 (even if 0)

3. **weak_topics** are topics with **< 60% accuracy**

4. **strong_topics** are topics with **≥ 80% accuracy**

5. **Trend detection:** Compare current score with previous quiz to identify improving/declining/stable

6. **AI uses:** weak_topics array to generate contextual feedback
